# Homework-1_ICA_Wines
Trabalho para a aplicação de conceitos aprendidos na cadeira de Inteligência Computacional Aplicada. O objetivo principal é realizar uma Análise Exploratória de Dados (Exploratory Data Analysis) rigorosa para entender a separabilidade linear e as distribuições de um dataset, e a implementação de um algoritmo de redução de dimensionalidade (PCA).
